# Norns

当前版本：**v0.6.1**。

面向小团队的中文、多账号任务看板。Rust / Axum / SQLx / SQLite 提供单服务，Svelte / TypeScript 界面由服务端托管。

## 功能

- 管理员统一创建、停用账号和重置密码。
- 按成员权限协作的看板，支持列表、卡片跨列移动、归档与恢复。
- 负责人、清单、评论、完成状态，以及日期、时间、时区和重复计划。
- 跨所在看板搜索未归档任务，可组合标题／描述关键词、看板、负责人、完成状态和日期筛选；打开原卡片编辑，返回时保留筛选。
- 卡片详情自动保存并显示保存状态；版本冲突显式处理并保留草稿。符合条件的未保存输入可在同一标签页刷新后明确恢复，见下文。
- 列表排序与卡片跨列拖放，明确显示可用落点；支持鼠标与触屏长按，手机仍可横向浏览并使用移动菜单。
- 服务端确认完成后，勾选与划线反馈短暂停留，再平滑收拢任务行；已完成任务单独展示，最近一次完成提供 10 秒撤销入口，并适配系统的减少动态效果设置。
- 跨看板月／周日历，按北京时间展示已安排日期的任务，可筛选看板并打开原卡片编辑。
- 重复计划支持跳过本次、撤销跳过和查看重复历史，完成、跳过与归档状态清晰区分。
- 看板所有当前成员均可移除列表：预览并选择同板目标列表，将全部任务与历史一起迁入，保留原卡片、评论、清单和附件。详见[操作说明](docs/recurrence-and-list-removal.md)。
- 连续勾选与详情自动保存共用排队写入，降低交互等待；冲突仍需明确处理。
- 可选私有 S3 兼容附件、鉴权下载和受限预览；未配置存储时仍可使用其他功能。
- 明确选择范围并预览后导出 CSV、JSON 或含就绪附件原件的 ZIP，见[导出说明](docs/exports.md)。
- 从已保存任务建立私人模板，在确认目标后复制为新任务，见[私人模板说明](docs/templates.md)。
- 在看板、智能视图或搜索中选择当前可见任务，经预览确认后原子批量修改同一看板的列表、日期、完成和归档状态，见[批量操作说明](docs/bulk-actions.md)。

适合单实例、小团队部署，通过轻量轮询更新协作内容。

## 私人工作区

三栏导航提供收集箱、分配给我、今天、明天和未来七天；登录后默认进入今天。私人收集箱仅本人可见。收集箱、智能视图和看板列表的新任务输入支持中文自然时间候选，例如「明天 上午9点 买牛奶」。点击「采用日期」后，日期随新任务一起保存；未采用时保留标题原文。在「今天」「明天」创建时，按提交瞬间的北京时间设置对应日期；「未来七天」需要明确选择一天。手动选择或已采用的日期优先，即使超出当前视图也会保留并提示去向。模板创建使用相同的日期规则，不重新解析模板标题。

收集箱任务可在确认后连同整条重复链转入普通看板，保留归档历史、评论、清单和附件。**转入后，目标看板当前及未来成员均可看到全部历史，请在确认前核对分享范围。**

界面提供蓝、鸢尾、陶土、石墨四种配色，分别搭配浅色、深色或跟随系统；偏好仅保存在当前浏览器，按账号隔离。

## 安装与联网使用

Norns 可在浏览器中使用，也可安装为独立窗口。正式站点须为 HTTPS。在支持的浏览器中，从页面「安装 Norns」查看说明，或使用地址栏／菜单中的安装选项。iPhone／iPad 请在 Safari 使用「共享」→「添加到主屏幕」；如有「作为网页 App 打开」则启用。

**编辑和保存需要联网。** 出现连接异常时，请留在原页，恢复连接后先核对保存结果，再继续操作，避免重复创建。离线重新打开会显示连接说明。

出现「有新版本」后，先在所有 Norns 标签页和独立窗口完成输入并核对保存结果，再关闭全部窗口并重新打开。请等进行中的操作结束后再更新，以免丢失未保存内容。

## 未保存输入与恢复

草稿保存在当前浏览器同一标签页，按账号隔离，最多保留 24 小时、20 条、合计 512 KiB。支持恢复新任务输入、已采用的日期、列表重命名，以及任务详情中的文本、日期、评论和清单输入。

请在关闭标签页前确认保存，尤其是新建看板、新建列表和附件上传。本地草稿会随标签页关闭、浏览器存储清理而丢失，重要内容应以服务器保存结果为准。

刷新后可选择恢复草稿，核对服务器最新内容后再确认保存。创建结果不明确时，先查找是否已创建，避免重复提交。退出登录会清除当前账号的本地草稿。

## 搜索与任务视图

进入「搜索」可搜索自己所在看板的未归档任务，不会展示无权限看板。关键词按标题和描述的字面子串匹配（`%`、`_` 不是通配符）；负责人选项来自有权限看板中未归档任务的负责人。筛选可组合使用。

- **我的任务**：由当前账号负责的任务；默认也包含已完成任务，可用完成状态进一步筛选。
- **今天**：按北京时间，展示已开始的有日期任务，包含逾期；完成任务单独折叠。
- **明天**：日期区间与明天相交。
- **未来七天**：今天至第六天，跨日任务只在首个可见日期出现一次，不提前生成重复实例。
- **即将到期**：未完成且截止日期在北京时间明天至未来第 7 天（含）的任务；范围任务取结束日，不含今天到期或逾期任务。
- **日期筛选**：任务起止范围与所选日期区间相交即匹配，含边界；支持只填一端，可查询逾期任务，无日期任务不匹配日期筛选。

## 日历与看板排序

进入「日历」可查看自己有权限看板的日期任务，支持月／周切换和单看板筛选，展示活动及已完成的有日期任务。点击任务可编辑原卡片，关闭后返回原日历位置。

拖动列表标题可调整列表顺序；拖动卡片内容可在同列或其他列的有效落点移动。未完成与已完成任务分别排列。也可通过列表更多菜单和卡片移动菜单操作。

## 复制任务摘要

打开任务详情，在「更多操作」中选择「复制已保存摘要」。纯文本摘要包含已保存的标题、描述、看板／列表、任务状态、负责人、日期、重复计划和清单。请先保存希望复制的编辑内容。

复制需使用支持剪贴板的浏览器及 HTTPS（本机开发可用 localhost）。浏览器提示权限时，请允许剪贴板后重试，也可手动选择详情文字复制。

## 本地分组与排序

在智能视图、搜索结果或看板中点击「显示」，选择分组和排序。智能视图与搜索支持按日期、按看板分组或平铺；普通看板保留列表结构，可切换日期排序与手动顺序。

显示偏好保存在当前浏览器，按账号、视图以及宽屏／窄屏分别记忆（800px 及以下为窄屏）。已完成任务与未完成任务分别排列。

日期排序只改变本地显示。要调整大家共用的任务顺序，请切回「手动顺序」后拖动，或使用卡片移动菜单。

## 升级注意

v0.6.1 沿用数据库结构 11，从 v0.6.0 升级无需新增迁移。日期创建与模板支持需要同时更新后端和前端。启动时会依次执行尚未应用的数据库迁移。v0.6.0 包含迁移 11，增加与完成互斥的「已跳过」状态，旧任务默认未跳过；迁移 9、10 的私人收集箱和模板数据继续保留。升级前应停止写入并制作 SQLite 一致性备份，同时保留附件对象及旧版本。**不要将旧二进制直接连接已升级的数据库**；旧版本不理解新的状态和权限边界。恢复方案必须以完整、相互匹配的数据备份为基础，并单独保护升级后的新增写入，避免覆盖或丢失用户数据。

升级步骤：

1. 在独立目录按下方命令构建目标版本，保留当前后端和静态资源。
2. 暂停访问并停止旧进程，制作 SQLite 一致性备份，同时保全附件对象和运行配置。
3. 一并替换后端可执行文件与 `frontend/dist`，继续使用原有数据库、附件配置及 `APP_ORIGIN`，启动新进程。数据库迁移会在启动时自动执行。
4. 检查登录、任务显示和附件访问后恢复使用。保留旧的带 hash 静态资源，供已打开的旧窗口加载；提醒用户保存后关闭全部窗口，再重新打开。

需要回退时，先停止服务，保全升级后的新增写入，再恢复与旧版本匹配的完整数据。**仅切换旧二进制或直接覆盖旧备份都可能破坏数据。**

跳过、重复历史与列表移除见[操作说明](docs/recurrence-and-list-removal.md)。

## 源码构建

需要 Rust 1.90.0（含 rustfmt、clippy）、Node.js 22、npm。SQLite 编入后端，无需另行运行数据库服务。

```sh
git clone --branch v0.6.1 --depth 1 https://github.com/AixPot/Norns.git
cd Norns
npm --prefix frontend ci
npm --prefix frontend run build
cargo build --release --locked
```

## 初始化与运行

从项目根目录运行。二进制只读取环境变量，不自动加载 `.env`；变量清单见 [.env.example](.env.example)。以下 Bash 示例仅用于本机 HTTP 开发：

```bash
umask 077
mkdir -p data
chmod 700 data
export DATABASE_URL="sqlite://$PWD/data/norns.sqlite"
read -r -s -p '新管理员密码（至少12字节）: ' NORNS_PASSWORD
printf '\n'
printf '%s' "$NORNS_PASSWORD" | ./target/release/norns init-admin admin
unset NORNS_PASSWORD
export BIND_ADDR=127.0.0.1:3000
export APP_ORIGIN=http://127.0.0.1:3000
export COOKIE_SECURE=false
export STATIC_DIR="$PWD/frontend/dist"
./target/release/norns
```

浏览器访问 `http://127.0.0.1:3000`。管理员初始化只在账号表为空时成功。请勿把密码放入命令行参数或使用示例测试账号部署。

正式环境使用 HTTPS 反向代理，将 `APP_ORIGIN` 设为浏览器实际 origin（不带尾斜杠），并保持 `COOKIE_SECURE=true`。后端监听受保护的本机地址，不直接对外暴露。`COOKIE_SECURE=false` 仅允许 loopback 绑定。保护数据库目录、备份和服务端密钥；会话与写请求受 Origin / CSRF 校验，不支持跨域 API。单个数据库和存储前缀只运行一个实例。

## 私有附件

五个 `S3_*` 变量全部留空可关闭附件；部分填写会拒绝启动。配置 `S3_ENDPOINT`、`S3_REGION`、`S3_BUCKET`、`S3_ACCESS_KEY_ID` 和 `S3_SECRET_ACCESS_KEY`；凭据只注入后端，禁止放入 `VITE_*` 或提交到 Git。应用不创建桶、不修复 ACL；部署者必须确认桶是私有的，并限制应用 key 的对象访问权限。

浏览器签名 PUT 需要桶 CORS 精确允许 `APP_ORIGIN`、PUT 和实际请求头（包括 Content-Type）；下载经同源鉴权代理，不需要开放浏览器 GET。默认单文件上限 16 MiB、看板配额 256 MiB，可通过 `.env.example` 中的附件变量调整，单文件最大 64 MiB。

对于保留历史版本的存储，DeleteObject 不保证物理清除旧版本。为 `norns/staging/` 设置上传残留与历史版本清理，为 `norns/final/` 仅清理非当前或已删除版本；**不要给仍有效的 final 当前版本设置无条件到期**。同时备份 SQLite 和对象，不要清空待处理的清理 outbox。

PDF 支持第一页预览，音视频播放取决于浏览器编解码器。部署时请对上传文件另行安排安全扫描；附件适合小文件协作。

## 开发与测试

```sh
sh scripts/verify.sh
# 已构建 release 后端与前端后：
python3 tests/http_smoke.py
```

`verify.sh` 安装锁定前端依赖，执行前端单元测试、类型检查、构建、Rust 格式检查、clippy、后端测试与 release 构建。

当前浏览器回归及可选存储测试的依赖、隔离规则和命令见 [测试说明](docs/testing.md)。这些测试仅使用自己创建的数据；不要传入生产数据库或生产桶。
