# Norns

当前版本：**v0.5.0**。

面向小团队的中文、多账号任务看板。Rust / Axum / SQLx / SQLite 提供单服务，Svelte / TypeScript 界面由服务端托管。

## 功能

- 管理员创建、停用账号和重置密码；无公开注册或默认密码。
- 看板成员权限、列表与卡片、跨列移动、归档与恢复；站点管理员不绕过看板成员权限。
- 负责人、清单、评论、完成状态，以及日期、时间、时区和重复计划。
- 跨所在看板搜索未归档任务，可组合标题／描述关键词、看板、负责人、完成状态和日期筛选；打开原卡片编辑，返回时保留筛选。
- 卡片详情自动保存并显示保存状态；版本冲突显式处理并保留草稿。符合条件的未保存输入可在同一标签页刷新后明确恢复，见下文。
- 列表排序与卡片跨列拖放，明确显示可用落点；支持鼠标与触屏长按，手机仍可横向浏览并使用移动菜单。
- 已完成卡片在原列置底淡化，不改手动排序；最近一次成功完成提供 10 秒撤销，重复任务的撤销受安全检查约束。勾选立即反馈，灰色勾号与「保存中」表示待确认，服务器确认后短暂停留并平滑补位；失败恢复，减少动态效果时不播放位移动画。
- 跨看板月／周日历，按北京时间展示已安排日期的任务，可筛选看板并打开原卡片编辑。
- 连续勾选与详情自动保存共用排队写入，降低交互等待；冲突仍需明确处理。
- 可选私有 S3 兼容附件、鉴权下载和受限预览；未配置存储时仍可使用其他功能。
- 明确选择范围并预览后导出 CSV、JSON 或含就绪附件原件的 ZIP，见[导出说明](docs/exports.md)。
- 从已保存任务建立私人模板，在确认目标后复制为新任务，见[私人模板说明](docs/templates.md)。
- 在看板、智能视图或搜索中选择当前可见任务，经预览确认后原子批量修改同一看板的列表、日期、完成和归档状态，见[批量操作说明](docs/bulk-actions.md)。

适合单实例、小团队。协作使用轻量轮询，不是即时同步；不提供离线队列、多副本、公开分享或密码自助找回。本地恢复不是备份；关闭标签页、清除或禁用浏览器存储及强制退出仍可能丢失未保存内容。

## 私人工作区

三栏导航提供收集箱、分配给我、今天、明天和未来七天；登录后默认进入今天。收集箱仅本人可见，站点管理员不能绕过权限。快速记录不自动设置日期或负责人。收集箱、智能视图和看板列表的新任务输入支持有限的中文自然时间候选（如「明天 上午9点 买牛奶」）；只有明确点击「采用日期」才随新任务一起保存日期，直接提交保留原文且不设置日期。编辑文字会取消已采用候选；现有任务标题编辑不自动解析日期。

收集箱任务可在确认后整条重复链转入有权限的普通看板，保留归档历史、评论、清单和附件。目标看板当前及未来成员将能看到全部历史；版本变化需要重新预览确认，结果未知时不自动重放。

界面提供蓝、鸢尾、陶土、石墨四种配色，分别搭配浅色、深色或跟随系统；偏好仅保存在当前浏览器，按账号隔离。

## 安装与联网使用

可选安装为独立窗口，使用现有 Norns 图标；不安装也能照常使用。正式站点须为 HTTPS。在支持的浏览器中，从页面「安装 Norns」查看说明，或使用地址栏／菜单中的安装选项。iPhone／iPad 请在 Safari 使用「共享」→「添加到主屏幕」；如有「作为网页 App 打开」则启用。无需通知权限。

**安装不提供离线编辑。** 无法连接时，已打开页面提示连接异常，请留在原页核对保存状态；失败或结果未知的操作不会因网络恢复自动补交。离线重新打开只显示公共连接说明（首次从未联网打开时可能是浏览器自己的错误页），不显示缓存的私人任务。任务、评论、附件和导出不进入 Service Worker 缓存；既有同标签页草稿恢复仍遵循下节边界，不等于服务器保存。

出现「有新版本」后，先在所有 Norns 标签页和独立窗口完成输入、明确保存并核对结果，再自行关闭全部窗口并重新打开。页面不会为更新自动刷新；仍有草稿、输入法组合输入、处理中操作或弹窗时不要为更新放弃内容。浏览器管理更新生效时机，保留其他旧窗口会延后更新。

## 未保存输入与恢复

草稿仅保存在当前浏览器同一标签页的 `sessionStorage`，按已登录账号隔离：最多 24 小时、20 条、合计 512 KiB。可恢复新任务输入（含明确采用的日期）、已有列表重命名和卡片详情中的文本、日期编辑、未发送评论与清单输入；**新建看板、新建列表的输入缓冲不在恢复范围**，附件文件和上传队列也不恢复。

刷新后须先重新确认账号及当前任务权限，再明确选择恢复。恢复不等于保存：详情会核对服务器最新值并保留待审阅状态，须另外确认才写入。结果未知的创建不会自动重放，应先核对是否已创建，避免重复。成功退出登录清除当前账号草稿；权限失效的目标不可恢复。存储不可用、过期或超限时仍可编辑，但不能保证恢复，也不代表服务器已保存。

## 搜索与任务视图

进入「搜索」可搜索自己所在看板的未归档任务，不会展示无权限看板。关键词按标题和描述的字面子串匹配（`%`、`_` 不是通配符）；负责人选项来自有权限看板中未归档任务的负责人。筛选可组合使用。

- **我的任务**：由当前账号负责的任务；默认也包含已完成任务，可用完成状态进一步筛选。
- **今天**：按北京时间，展示已开始的有日期任务，包含逾期；完成任务单独折叠。
- **明天**：日期区间与明天相交。
- **未来七天**：今天至第六天，跨日任务只在首个可见日期出现一次，不提前生成重复实例。
- **即将到期**：未完成且截止日期在北京时间明天至未来第 7 天（含）的任务；范围任务取结束日，不含今天到期或逾期任务。
- **日期筛选**：任务起止范围与所选日期区间相交即匹配，含边界；支持只填一端，可查询逾期任务，无日期任务不匹配日期筛选。

## 日历与看板排序

进入「日历」可查看自己有权限看板的日期任务，支持月／周切换和单看板筛选；含已完成任务，不显示归档或无日期任务。点击任务可编辑原卡片，关闭后返回原日历位置。时间轴仅用于展示，不提供提醒或通知。

拖动列表标题可调整列表顺序；拖动卡片内容可在同列或其他列的有效落点移动。未完成与已完成分组始终保留，不能跨分组任意插入。列表更多菜单和卡片移动菜单可作为非拖放操作入口。触屏模拟已验证，物理手机和 Safari 仍需实机确认。

## 复制任务摘要

打开任务详情，在「更多操作」中选择「复制已保存摘要」。摘要为纯文本，包含已保存的标题、描述、看板／列表、完成与归档状态、负责人、日期／重复和清单。**不包含尚未保存的编辑、未发送评论或清单输入，也不包含评论和附件链接。** 复制不会代替保存或发送输入；正常自动保存仍照常运行。

仅在剪贴板写入成功后显示成功提示。若浏览器拒绝权限，可允许剪贴板后重试，或手动选择详情文字复制；需使用支持剪贴板的浏览器及 HTTPS（本机开发可用 localhost）。

## 本地分组与排序

在智能视图、搜索结果或看板中点击「显示」，选择「分组」或「排序」。智能视图与搜索支持默认、不分组、按日期或按看板分组；普通看板保留原列表列结构，仅提供排序。日期排序只是当前浏览器、当前账号的显示偏好，不写入共享任务顺序；切回「手动顺序」即可恢复真实顺序。不同视图分别记忆选择；桌面／宽屏与手机／窄屏也分别记忆（与导航布局一致，以 800px 为界，窄屏包含 800px）。已有显示偏好会作为两种宽度的初始值，分别修改后互不覆盖；没有有效旧值时使用默认分组、手动顺序。这是当前浏览器的宽度分类，不是跨设备或云同步。存储不可用时仍可在当前页面操作，但刷新后可能不保留。已完成任务仍与未完成任务分开；跨日任务不会因分组重复出现，也不会提前生成重复实例。

按日期排序时不能拖动卡片重排；要调整共享顺序，先切回手动顺序，或使用明确的移动菜单。切换显示选项不应关闭详情或清空未发送输入。本地显示偏好不包含在任务导出中。

## 升级注意

启动时会依次执行尚未应用的数据库迁移。迁移 9（v0.3.0）为已有账号建立私人收集箱；当前源码还包含迁移 10，新增私人模板、模板清单条目和清单 ID 高水位记录，保留现有任务与清单数据。升级前须停止写入并使用 SQLite 一致性备份，保留旧二进制与附件对象。**不能仅换回旧二进制继续使用新 schema**：旧版权限逻辑不理解私人收集箱。回滚必须停服、保存当前数据、恢复升级前数据库及对应旧版本；升级后的新增写入不会存在于旧备份中，需另行恢复。

## 构建

需要 Rust 1.90.0（含 rustfmt、clippy）、Node.js 22、npm。SQLite 编入后端，无需另行运行数据库服务。

```sh
npm --prefix frontend ci
npm --prefix frontend run build
cargo build --release --locked
```

## 初始化与运行

从项目根目录运行。二进制只读取环境变量，不自动加载 `.env`；变量清单见 [.env.example](.env.example)。以下 Bash 示例仅用于本机 HTTP 开发：

```bash
umask 077
mkdir -p data
chmod 700 data
export DATABASE_URL="sqlite://$PWD/data/norns.sqlite"
read -r -s -p '新管理员密码（至少12字节）: ' NORNS_PASSWORD
printf '\n'
printf '%s' "$NORNS_PASSWORD" | ./target/release/norns init-admin admin
unset NORNS_PASSWORD
export BIND_ADDR=127.0.0.1:3000
export APP_ORIGIN=http://127.0.0.1:3000
export COOKIE_SECURE=false
export STATIC_DIR="$PWD/frontend/dist"
./target/release/norns
```

浏览器访问 `http://127.0.0.1:3000`。管理员初始化只在账号表为空时成功。请勿把密码放入命令行参数或使用示例测试账号部署。

正式环境使用 HTTPS 反向代理，将 `APP_ORIGIN` 设为浏览器实际 origin（不带尾斜杠），并保持 `COOKIE_SECURE=true`。后端监听受保护的本机地址，不直接对外暴露。`COOKIE_SECURE=false` 仅允许 loopback 绑定。保护数据库目录、备份和服务端密钥；会话与写请求受 Origin / CSRF 校验，不支持跨域 API。单个数据库和存储前缀只运行一个实例。

## 私有附件

五个 `S3_*` 变量全部留空可关闭附件；部分填写会拒绝启动。配置 `S3_ENDPOINT`、`S3_REGION`、`S3_BUCKET`、`S3_ACCESS_KEY_ID` 和 `S3_SECRET_ACCESS_KEY`；凭据只注入后端，禁止放入 `VITE_*` 或提交到 Git。应用不创建桶、不修复 ACL；部署者必须确认桶是私有的，并限制应用 key 的对象访问权限。

浏览器签名 PUT 需要桶 CORS 精确允许 `APP_ORIGIN`、PUT 和实际请求头（包括 Content-Type）；下载经同源鉴权代理，不需要开放浏览器 GET。默认单文件上限 16 MiB、看板配额 256 MiB，可通过 `.env.example` 中的附件变量调整，单文件最大 64 MiB。

对于保留历史版本的存储，DeleteObject 不保证物理清除旧版本。为 `norns/staging/` 设置上传残留与历史版本清理，为 `norns/final/` 仅清理非当前或已删除版本；**不要给仍有效的 final 当前版本设置无条件到期**。同时备份 SQLite 和对象，不要清空待处理的清理 outbox。

PDF 仅第一页受限预览；音视频支持取决于浏览器编解码器。没有转码或杀毒功能。Range 仍可能从存储读取完整受限文件，不适合大视频。

```sh
sh scripts/verify.sh

python3 tests/http_smoke.py
```

`verify.sh` 安装锁定前端依赖，执行前端单元测试、类型检查、构建、Rust 格式检查、clippy、后端测试与 release 构建。

当前浏览器回归及可选存储测试的依赖、隔离规则和命令见 [测试说明](docs/testing.md)。这些测试仅使用自己创建的数据；不要传入生产数据库或生产桶。
