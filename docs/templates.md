# 私人任务模板

打开任务的「更多操作」→「保存为私人模板」。界面先通过现有自动保存通道确认任务内容；IME、失败或冲突、无效日期、未发送的评论/清单/附件，以及尚未明确确认保存的恢复草稿，都不能绕过此步骤。预览显示已确认保存的标题、描述和有序条目，然后填写名称并明确保存。服务器按看板版本和任务 touch_version 读取持久化源，不接收编辑器正文作为快照。

从导航「清单」旁的更多操作打开「私人模板库」，选择模板后可修改名称、任务标题、描述和有序条目，或确认删除。模板仅所属账号可读写；已有任务与模板完全独立。保存/删除使用模板版本 CAS，冲突不自动重试；失败保留窗口内的编辑。重新读取需明确放弃未保存修改。

任务录入框旁「模板」按钮使用当前明确的收集箱/列表作为目标。选择模板并预览后确认创建；不解析自然语言，也不改变原录入文本及已采用日期。普通看板（包括只有一名成员的看板）必须明确勾选共享可见性确认；当前及未来成员都可能看到复制的内容。自己的私人收集箱不需要共享确认。

只复制标题、描述和条目标题及顺序。任务和条目有新 ID，完成/归档/勾选均重置；日期、重复、负责人、评论和附件不复制。目标创建经过原有单一看板写入队列及一次 CAS。源版本、模板版本或目标版本变化时必须重新读取并核对，不自动重试。

网络中断可能发生在写入已提交之后。结果未知时阻止重复保存/创建，当前标签页以账号隔离的无内容安全标记保留阻止状态（包括刷新页面）。先只读核对模板和目标任务，再明确解除阻止；不会自动重放。浏览器禁止 sessionStorage 时只能维持当前页面内的阻止，应先核对再离开。模板编辑不是跨页面恢复的草稿库，关闭未保存编辑会要求确认。

模板窗口是唯一顶层对话框；下层任务编辑器保持挂载但暂停交互。关闭后恢复原输入焦点和选区，恢复草稿仍保持未确认状态。账号切换或窗口销毁会取消旧模板读取，旧响应不能写入新账号界面。

导出仍为明确选择的任务应用数据，**不含私人模板库或本地显示偏好**，不自动改变 CSV/JSON/ZIP 模式；详见 [导出说明](exports.md)。
