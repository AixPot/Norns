# 跳过、重复历史与安全移除列表

## 跳过本次重复任务

在任务详情中预览并确认跳过本次。服务端计算真实下一次；最后一次不会凭空生成后继。原任务保留身份、评论、清单和附件，标记为「已跳过」，不算完成；归档仍是独立状态。默认活动视图和日历不显示跳过项，搜索可按已跳过筛选，重复历史包含真实的归档记录，不预生成未来实例。

撤销跳过只在安全条件满足时收回未触碰的直接后继。后继已编辑、处理、归档或拥有评论、附件等资源时会拒绝撤销，避免删除用户数据；不能把撤销当作总能成功的回退。

## 将任务迁出后移除列表

普通看板的所有当前成员均可选择同板目标列表，读取完整预览并确认。操作一次性迁移源列表全部任务，包括完成、跳过和归档历史，再移除空壳；不是逐条复制或删除任务，没有批量选择的 100 条限制。原卡片 ID、评论、清单和附件保持不变。

目标必须是同一看板中的其他列表。私人收集箱及最后一个列表不能这样移除；附件仍在上传或验证时会阻止操作。请先完成输入并核对保存状态。

## 确认与数据保护

预览后数据、权限或附件状态变化，会要求重新预览确认。冲突、明确失败或响应未知不会自动重放；结果未知时先核对最新状态，避免重复提交。迁移或跳过后的资源变化可能使先前撤销被保守拒绝。

完成操作的「保存中」不是成功。只有服务端确认才显示完成落印，最近一次确认提供十秒撤销入口；下一条保存中不会抢走上一条确认提示。减少动态效果时保留静态确认，不强制等待动画。跳过不会冒充完成反馈。

导出保留已跳过状态，跳过不计入完成筛选，归档筛选仍单独生效。联网恢复或重开弹窗不代表写入已经成功，也不会自动补交未知操作。
