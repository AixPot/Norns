# 跳过、重复历史与安全移除列表

## 跳过本次重复任务

打开重复任务详情，选择跳过本次，核对预览后确认。当前任务会标记为「已跳过」，保留评论、清单和附件；有下一次计划时，会生成后续任务。

在「重复历史」中可查看已经产生的各次任务及归档记录，搜索支持按已跳过状态筛选。完成、跳过和归档是分别记录的状态，导出也会保留跳过状态。

如需撤销，可在后续任务尚未被编辑、处理、归档或添加评论、附件等内容时撤销跳过。后续任务已有变动时，请直接调整任务，保留已有内容。

## 将任务迁出后移除列表

普通看板的所有当前成员均可在列表菜单中选择移除列表，指定同板目标列表，核对预览后确认。源列表的全部任务，包括完成、跳过和归档历史，会一并迁入目标列表，然后移除原列表。原卡片 ID、评论、清单和附件保持不变。

目标必须是同一看板中的其他列表。私人收集箱及最后一个列表不能这样移除；附件仍在上传或验证时会阻止操作。请先完成输入并核对保存状态。

## 确认与数据保护

如果预览后任务或权限发生变化，请重新预览并确认。操作结果不明确时，先查看任务和列表的最新状态，避免重复提交。

## 完成反馈

完成任务时先显示「保存中」，保存成功后出现落印反馈和十秒撤销入口。连续完成任务时，可撤销最近一次成功完成的任务。启用系统的减少动态效果设置后，会以静态提示确认完成。
