# 导出所选数据

从左侧导航的「清单」标题旁打开「更多操作（⋯）」→「导出数据」。手机上先打开导航。日历、搜索和智能视图也使用同一入口。

## 范围与预览

- 普通看板默认只选择当前看板；聚合视图默认只选择自己的「收集箱（仅自己）」。不会默认选择全部看板。
- 可明确勾选自己的收集箱和当前有权访问的协作看板，最多 20 个。不继承搜索关键词、日历日期或智能视图筛选。
- 「包含已完成任务」与「包含已归档任务」是独立选项，默认包含已完成、不包含已归档。
- 点击「获取最新导出预览」，核对任务、清单条目、评论、附件元数据数量及大小，再明确确认下载。改变范围、状态或格式后必须重新预览。
- 数据、权限或附件变化可能使下载失败；重新预览并核对后再明确下载。不会自动重试或截断内容。

## 文件格式

**CSV** 是 UTF-8 BOM 任务表，保留中文、引号与多行文本。电子表格公式样式的文本可能带安全前缀单引号。每行包含任务字段及相关条目数量，不包含完整评论、清单条目或附件原件。

**JSON** 包含所选看板、列表、任务、日期和重复设置、清单条目、评论、附件元数据及相关用户。附件内容、账号凭据与存储地址不包含在其中。不隐式展开未选中的重复链历史；要包含已归档或已完成历史，须明确选择对应范围及状态选项。

**ZIP** 包含 `data.json`、`tasks.csv`、`manifest.json` 和就绪附件原件。预览分别显示附件元数据总数、就绪原件数量/字节和非就绪排除数。待上传、校验中及已删除的记录保留元数据，但不包含原件，并在清单中记录排除原因。预览不读取原件，因此不保证下载时原件可用；缺少任何应包含的原件会使整个包失败，不提供成功子集。

ZIP 内附件使用安全生成的路径；原始文件名保留在元数据中。清单记录包内文件实际大小和 SHA-256。校验和只证明本包字节，不能证明附件自上传以来未被带外改写。

## 限制与取消

最多 5,000 个任务、20,000 条附属记录。CSV/JSON 单个文件最多 16 MiB；ZIP 的 JSON 与 CSV 元数据合计最多 16 MiB。ZIP 最多 200 个原件，合计 128 MiB、单个最多 64 MiB（还受服务端配置限制），最终包最多 160 MiB。超限时请缩小范围。

浏览器先完整接收有界文件到内存，再交给浏览器下载，不是流式直接保存。移动设备请优先选择小范围。「取消当前导出」、关闭窗口或身份切换会中止本次接收；已经交给浏览器的文件不能撤回。

这是所选应用数据，不是数据库或灾难恢复备份，也不是承诺可直接导入的格式。下载文件可能包含私密内容，请在可信设备上妥善保存。

私人模板库和当前设备的分组、排序等本地显示偏好均不包含在导出中；模板功能不会自动改变导出文件的模式或范围。
